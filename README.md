# canvas_apps
Apps for Canvas using the API

The canvas_apps folder is a library of tools that the various programs use.

# How to Connect
```
canvas = connect(INSTITUTION)
```
Here, `INSTITUTION` is the institution URL, as in `INSTITUTION.instructure.com`. To connect, you will need to have an API key from the appropriate Canvas instance as a text file in the same folder as the script you are using.
